slv.measurements.mobile#

Mobile-platform measurements: the TRAX light-rail trains and the Wyoming mobile lab.

Submodules, one concern each:

  • network — TRAX lines, staged points, storage yards (JRRSC, MRSC), shed footprints, route-buffer filter.

  • gps — GPS readers (lin-group air-trend, horel-group CR1000 logger, era-based read_trax_gps()) and merge_with_gps().

  • location — per-minute location classifier: indoor (shed) vs outdoor (yard / pass-by / route / stopped), state / indoor / yard_name.

  • calibration — cal_source provenance and the uncalibrated windows.

  • obs — build_trax_obs() / load_trax_obs(), the cached CH4 record with both tag sets and a load-time location filter.

  • transects — transect matrices obs[transect, point]: the network builder (build_network_transects() / build_trax_transects() / load_network_transects()) and the archived per-line matrices (load_transects()).

  • receptors — STILT receptors: 50-m network points, 2-km segment crossings, one PYSTILT multipoint receptor per crossing, and dwell (parked-train) receptors.

  • receptor_obs — the CH4 observation for each of those receptors, keyed (obs_location, obs_time) exactly as the inversion joins them to the footprints.

  • wyoming — the Wyoming mobile lab (Aeris + met readers, enhancement ratios, wind-barb map); not re-exported, import from the module.

Every public function and table is re-exported here, so from slv.measurements.mobile import X works for all of them; the classifier thresholds (location) and GPS column/flag constants (gps) stay in their modules.

Modules

calibration

Calibration provenance of the TRAX CH4 record: cal_source tags and the windows where the analyzer ran without a reference tank but its raw data are usable.

gps

GPS records for the mobile platforms and the observation/GPS merge.

location

Where is the TRAX train, minute by minute: indoor (shed), yard, pass-by, route, stopped?

network

The TRAX network and its yards: line geometry, staged points, storage polygons, shed footprints, and the route-buffer filter used by the GPS merge.

obs

The georeferenced TRAX CH4 observation record: build it from the pipeline levels, tag every row with calibration provenance and location, cache it, and load it with a location filter.

receptor_obs

TRAX CH4 observations paired one-to-one with the STILT receptors.

receptors

STILT receptors for the TRAX record: one multipoint receptor per 2-km segment crossing.

transects

TRAX transect matrices: obs[transect, point] over the 50-m network points.

wyoming

Wyoming mobile lab: Aeris CH4/C2H6 and vehicle met readers, enhancements and C2/C1 ratios, and a wind-barb map of a drive.
