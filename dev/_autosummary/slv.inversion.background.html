slv.inversion.background.get_slv_background(background, obs_times, sites, site_config, time_range, num_processes=1, filter_pcaps=False, **kwargs)[source]#

Dispatch background calculation by type.

Returns Series with obs_time index and background concentration. The hourly rolling baseline is looked up for the hour each obs time falls in, so a mobile receptor released at 20:13 gets the 20:00 background (an exact-time join would leave it NaN and drop it).

Return type:

Series

slv.inversion.background.get_rolling_background(sites, site_config, time_range, num_processes=1, filter_pcaps=True, baseline_window='14d', min_periods=84, background_sites=None)[source]#

Hourly rolling 1st-percentile baseline, averaged over the stationary sites.

The baseline comes from the towers: mobile sites in sites are left out (a train sampling the urban core is not a background site, and its per-grid-point rows do not form one hourly series). background_sites picks the sites explicitly instead, e.g. towers for a TRAX-only inversion (background_kwargs={"background_sites": [...]}).

Return type:

Series

slv.inversion.background.get_ct_stilt_background(obs_times, csv_path, value_col='ct_ch4_ppm', **kwargs)[source]#

CarbonTracker-STILT endpoint background [ppm], joined to obs by UTC date.

Reads the daily CT-STILT background product (built by sampling the CarbonTracker-CH4 field at STILT trajectory endpoints – see lair.noaa.CarbonTracker.background + stilt.Trajectories.endpoints) and aligns it to obs_times by date. csv_path is passed explicitly (e.g. via background_kwargs) so the package stays decoupled from any workspace layout. Obs whose date is absent from the product get NaN.

Return type:

Series
