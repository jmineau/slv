slv.inversion.viz.plot_mdm_components(components)[source]#

Plot the total error magnitude for each MDM error component.

Parameters:

components (dict of str to pd.DataFrame) – Dictionary where keys are component names and values are covariance matrices as DataFrames with symmetric indexes.

Notes

The total error is computed using the Frobenius norm of the covariance matrix, which includes contributions from off-diagonal elements (correlations).

slv.inversion.viz.plot_desroziers(by_site, per_obs, timeseries)[source]#

Plot Desroziers diagnostic: variance comparison, box-whisker, and timeseries.

Parameters:

  • by_site (pd.DataFrame) – Site-aggregated Desroziers diagnostic (default groupby) with ‘diagnosed’, ‘specified’, and ‘ratio’ columns.

  • per_obs (pd.DataFrame) – Per-observation Desroziers diagnostic (groupby=None) with ‘diagnosed’, ‘specified’, and ‘ratio’ columns. Index should have ‘obs_location’ and ‘obs_time’ levels.

  • timeseries (pd.DataFrame) – Temporally-aggregated Desroziers diagnostic with ‘ratio’ column. Index should have ‘obs_location’ and ‘obs_time’ levels.

slv.inversion.viz.plot_background_and_bias(problem)[source]#

Plot background concentration and bias corrections.

Parameters:

problem (FluxProblem) – Solved inversion problem containing prior, posterior, and constant.

Notes

  • If bias exists, creates two subplots: background and bias

  • If no bias, only plots background

  • Background: automatically detects if all sites share the same regional background (plots single line) or have site-specific backgrounds (plots separate lines)

  • Bias is shown as prior (initial) and posterior (estimated) values

  • For grouped bias (site/site_group), each group gets its own line
